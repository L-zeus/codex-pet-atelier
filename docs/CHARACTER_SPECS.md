# 角色一致性规范 / Character Sheets

本文件记录对用户五张参考图的设计理解；不是素材授权证明。所有系列都以**原画保真**为主、轻微改善为辅。

## blue-whale-maid（首发，LOCAL_ONLY_RIGHTS_PENDING；GUI 为 USER_REPORTED；逐状态待证）

- 参考：`references/private/blue-whale-maid-02.jpg`（主参考，正面挥手），`blue-whale-maid-01.jpg`（辅助确认姿态、裙摆和配色）。
- 识别锚点：深蓝到浅蓝渐变的长卷发；蓝色大眼睛；白色蕾丝女仆发箍；侧边蓝色蝴蝶结；侧鳍/海洋耳部结构；深蓝白色裙装；围裙上的小鲸鱼图案；裙摆花纹与小蝴蝶结；长鲸尾；白袜与深蓝鞋。
- 服装版本固定 02 的较短钟形裙、全肩长袖、白褶边袖口、深蓝领结与蓝宝石；不混入 01 的露肩长裙。正面观看的右侧蓝蝴蝶结与围裙鲸图按人物身体侧追踪，不能直接镜像。
- 表情：友善、有活力，眼睛比例尽量贴近参考。不要变成脸更圆、头更大、衣服完全重画的全新角色。
- 动效：轻微眨眼、长发摆动、尾鳍轻摆、实际挥手和跳跃；工作/审阅时可轻微调整目光与手部动作，不强行增加电脑等道具。
- 方向感：头饰和围裙图案是非对称元素，左右行必须单独确认。镜像变形不是默认方案。

## orange-scholar（V1.1，LOCAL_ONLY_RIGHTS_PENDING；GUI 为 USER_REPORTED；逐状态待证）

- 主参考：`orange-scholar-02.jpg` 固定面部与比例；01只交叉核对服饰与细节。
- 锚点：橙色长发，花朵发夹与颈前花饰，奶白/黑/橙配色多层礼裙，金色线条和流苏，棕色花纹封面书本。
- 表情：沉静、略带知性，不能无理由改成夸张欢笑大眼。
- 动效：翻书/抬眼审阅、长发轻摆、书本位置连续。
- 橙花与黑结保持人物左侧，书本由右侧手臂支撑；左右动作独立生成，不自动镜像。

## silver-dragon（V1.1，LOCAL_ONLY_RIGHTS_PENDING；GUI 为 USER_REPORTED；逐状态待证）

- 参考：`silver-dragon-01.jpg`。
- 锚点：银白长发、浅紫眼睛、弯曲白龙角、淡紫白龙翼、鳞片状长尾、浅紫白色服饰及结饰。
- 表情：安静、柔和。蓝眼小云灵固定为独立辅助元素，靠近人物左掌，不融合成人体结构；保持单格安全边距。
- 动效：翅膀轻摆、龙尾弧线连贯，不能在动作间消失或改变角形。

## 共同红线

- 单格 `192×208` 的清晰度优先，不强求原图所有细小花纹都逐像素可见。
- 同一个角色的发长、袖型、鞋型、色系、面部特征和五官位置保持稳定。
- 不同动作必须变化“姿态/表情/身体部位”，不能只横向位移同一张贴图。
