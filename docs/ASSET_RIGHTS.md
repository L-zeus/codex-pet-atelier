私有生成、预览与本机安装验收不改变上表的 `UNVERIFIED` 状态。原图和衍生美术均留在 `references/private/`、`workruns/` 等忽略目录，不进入公开 `pets/`、README 远程图片或 GitHub 附件。GUI 截图还需要检查其中的界面隐私。

发行证据必须绑定具体 `pet.json` 和 `spritesheet.webp` 的 SHA-256，明确许可来源、确认人、允许公开再分发与衍生，以及证明文件的路径和哈希。`package_release.py` 同时检查视觉和 GUI 验收记录。检查记录与哈希不能证明声明本身真实，发布者仍须人工核对授权。未确认时不得填写 `VERIFIED` 通过门禁。
